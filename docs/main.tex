\begin{abstract}
\texttt{MOF\_benchwork} is a reproducible benchmark pipeline for gas adsorption simulations in metal-organic frameworks.
The project currently focuses on Module A, single-component CO2 adsorption in rigid MOF-5/IRMOF-1, and is designed to grow into mixture adsorption, Widom/Henry calculations, force-field comparisons, and flexible-framework simulations.
This document is intended as a living technical and scientific documentation of the project.
\end{abstract}
